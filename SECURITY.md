# Security

If you find a security problem in an Omuk app or on omuk.dev, report it privately.
Do not open a public issue.

1. Go to [omuk.dev/support](https://omuk.dev/support/).
2. Select the app, or "Something else" for the website.
3. Start the message with "Security".
4. Tell what the problem is, how to make it happen, and which version you use.

A fix for a confirmed problem ships as an app update, and the release notes say what it fixed.
